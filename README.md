# Tajweed · تعلّم التجويد

Beginner tajweed lessons in Arabic and English, with animations beside the text and color-coded Quran examples with audio. Installable as an offline web app (PWA) from https://muhammadmoustafa.github.io/tajweed/, or on Android as an APK: [tajweed.apk](https://github.com/MuhammadMoustafa/tajweed/releases/latest/download/tajweed.apk) (the newest release; open it on the phone and allow installing from that source). Coming from the preview app before v0.2.0? Uninstall it first; later versions install over it, and the app offers each new one.

Releases are published by the maintainer with `npm run release` (see CLAUDE.md, Distribution).

```bash
npm install
npm run dev
```

Quran text: Quran Foundation API (`text_uthmani_tajweed`, Hafs). Recitation audio: EveryAyah (Mishary Alafasy).
