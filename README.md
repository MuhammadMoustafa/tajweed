# Tajweed · تعلّم التجويد

Beginner tajweed lessons in Arabic and English, with animations beside the text and color-coded Quran examples with audio. Installable as an offline web app (PWA).

```bash
npm install
npm run dev
```

Quran text: Quran Foundation API (`text_uthmani_tajweed`, Hafs). Recitation audio: EveryAyah (Mishary Alafasy).
